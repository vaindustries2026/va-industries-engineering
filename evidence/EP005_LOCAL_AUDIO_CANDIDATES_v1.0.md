## 1. Method

- **Script:** `evidence/ep005/audio_candidates/generate_ep005_audio_candidates_v1.sh`. It contains no URLs and no network commands.
- **Tool:** ffmpeg 6.1.1-3ubuntu5, built-in lavfi signal sources only. `anoisesrc` (pink noise) uses fixed seeds; `aevalsrc` evaluates a mathematical expression.
- **Inputs:** none. No external samples.
- **Output format:** WAV, PCM 24-bit, 48 kHz. Written with `-fflags +bitexact`, and all metadata stripped (`-map_metadata -1`).

**Ambience recipe:**
- Stereo, built from two decorrelated pink-noise sources and band-limited.
- Made seamless with an equal-power 3 s crossfade of the tail into the head. The output is `A[3:40] ++ mix(A[40:43] fading out, A[0:3] fading in)`, a 40 s loop.
- A very slow ±0.7 dB level drift whose period equals the loop length, so the loop stays seamless.

**Pop recipe:**
- A mono damped sine whose frequency glides quickly downward: f(t) = F1 + (F0−F1)·e^(−t/τ).
- Envelope: a 1.5–3 ms attack, then a 45–70 ms exponential decay.
- A gentle low-pass, and a 20 ms fade to true zero at the end.

**Offline and deterministic:**
- The script was run **twice**, each time inside an empty Linux network namespace (`unshare -n`, which has no network interfaces at all).
- Both runs produced byte-identical files: all 6 SHA-256 values match.
