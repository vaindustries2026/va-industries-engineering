## 1. Rules that apply to every identity

| Rule | Contract |
|---|---|
| ID-1 Type | `uuid`. Generated by the database (`DEFAULT gen_random_uuid()`) at row insert. Never generated by an LLM, never typed by a human, never derived from a title, filename, caption or label. |
| ID-2 Immutability | A primary key never changes and is never reused, even after the row is RETIRED or REJECTED. |
| ID-3 Revisions | Content objects (opportunities, scripts, source packages, manifests, renders) are immutable once they leave `DRAFT`. A change is a **new row with a new ID**, linked by `revision_of_<x>_id` and a deterministic `revision_number`. An approval never carries over to a new revision. |
| ID-4 Labels | Every object may have display fields (title, working_hook, filename…). They are mutable while DRAFT, never unique, never used in joins or lookups by workflows. |
| ID-5 Natural keys | Dedupe uses an explicit natural key or `dedupe_key` (sha256 of normalised fields) with a UNIQUE constraint. The natural key is for dedupe only; references always use the UUID. |
| ID-6 Lookup by label | A workflow that receives a label instead of a UUID must resolve it to exactly one UUID or **fail closed** (`AMBIGUOUS_IDENTITY` / `IDENTITY_NOT_FOUND`). It may never pick "the latest" or "the first". |
| ID-7 Malformed input | Any ID input that is not a canonical lowercase UUID fails validation before any read or write (`MALFORMED_UUID`). |
| ID-8 External IDs | IDs owned by other systems (YouTube video ID, TikTok post ID, AniList ID, Gemini interaction ID) are stored as attributes with their own UNIQUE constraint. They are never our primary key. |
| ID-9 Provenance | Every row written by an agent carries `agent_run_id` (FK to `agent_runs`). Every human decision carries `reviewer_id`. |
| ID-10 Manual assignment | Humans never assign a primary key. Humans choose *which existing ID* they are approving, and the governance surface passes that UUID. |

## 2. Identity register

Columns: **Owner** = the only process allowed to create the row. **Consumers** = downstream readers that take the ID as input.

### 2.1 Reference identities

#### `franchise_id` (table `anime_franchises`) — added in Sprint 0
- **Owner:** CF-001 (proposes) with deterministic resolver; humans may correct via a governed edit.
- **Created when:** a research candidate references a franchise not yet registered.
- **Immutability:** ID-1/2. `display_name` mutable.
- **Consumers:** anime_titles, research_candidates, analytics (CF-009), wrong-franchise contamination tests.
- **Dedupe:** `normalised_key` UNIQUE (lowercase, ASCII-folded, punctuation stripped, romaji form) plus optional `anilist_franchise_ref` UNIQUE. A near-match (edit distance ≤ 2) is not auto-merged: it goes to `BLOCKED` for human resolution.
- **FKs:** none upstream.
- **Human-assigned?** No.

#### `anime_title_id` (table `anime_titles`)
- **Owner:** CF-001 title resolver (deterministic). CF-002 may request creation through the same resolver, never by direct insert.
- **Created when:** a title is first referenced and resolves to an external registry entry, or a human registers it.
- **Immutability:** ID-1/2. One row per *work* (a series season-group or film), not per season label.
- **Consumers:** research_candidates, anime_source_episodes, anime_scene_intelligence, editorial_opportunities, performance joins.
- **Dedupe:** `anilist_id` UNIQUE where not null; `mal_id` UNIQUE where not null; else `(franchise_id, normalised_title_key, start_year)` UNIQUE. If no external ID and the fallback key collides with different metadata → `BLOCKED` (`AMBIGUOUS_SOURCE_IDENTITY`).
- **FKs:** `franchise_id → anime_franchises`.
- **Human-assigned?** No (humans may supply the AniList/MAL ref that the resolver uses).

#### `source_episode_id` (table `anime_source_episodes`)
- **Owner:** CF-002 episode resolver (deterministic).
- **Created when:** the first scene in that episode is logged.
- **Immutability:** ID-1/2.
- **Consumers:** anime_scene_intelligence, publication_source_items (as the work the material depicts).
- **Dedupe:** `(anime_title_id, season_number, episode_number, episode_variant)` UNIQUE. `episode_variant` defaults to `'TV'` (other values: `OVA`, `MOVIE`, `SPECIAL`, `RECAP`, `DIRECTORS_CUT`). Missing season/episode number → row is not created; the scene is `BLOCKED`.
- **FKs:** `anime_title_id → anime_titles`.
- **Human-assigned?** No.

### 2.2 Intelligence identities

#### `research_candidate_id` (table `research_candidates`)
- **Owner:** CF-001 only.
- **Created when:** CF-001 run produces a validated candidate.
- **Immutability:** ID-1/2; signal fields immutable once `READY` (a newer observation is a new row in a new window).
- **Consumers:** CF-002 (what to investigate), CF-003 (context), CF-009 (attribution).
- **Dedupe:** `dedupe_key = sha256(anime_title_id | topic_key | content_lane | observation_window)`, UNIQUE. `observation_window` = ISO week (`2026-W41`). Replay in the same window returns the existing row.
- **FKs:** `anime_title_id`, `franchise_id`, `agent_run_id`.
- **Human-assigned?** No.

#### `scene_id` (table `anime_scene_intelligence`)
- **Owner:** CF-002 only (including human-logged scenes, which enter through the CF-002 intake path so they get the same validation).
- **Created when:** a scene passes provenance validation.
- **Immutability:** ID-1/2. Timestamps and episode link immutable once `READY`; corrections create a new scene that `supersedes_scene_id`.
- **Consumers:** CF-003, CF-004 (evidence), CF-005 (what material is needed), CF-009.
- **Dedupe:** `dedupe_key = sha256(source_episode_id | floor(start_ms/1000) | ceil(end_ms/1000))` UNIQUE. A second scene overlapping an existing one by ≥ 80% of the shorter span is flagged `possible_duplicate_of_scene_id` and held at `DRAFT` for review; it is never merged automatically.
- **FKs:** `source_episode_id`, `anime_title_id` (denormalised, CHECK-consistent), `research_candidate_id` (optional), `agent_run_id`.
- **Human-assigned?** No.

### 2.3 Editorial identities

#### `content_candidate_id` (table `editorial_opportunities`)
- **Owner:** CF-003 only.
- **Created when:** CF-003 persists a ranked idea at `IDEA`.
- **Immutability:** ID-3 — editorial fields frozen once `REVIEW`. G1 approves this exact ID.
- **Consumers:** G1, CF-004, CF-009.
- **Dedupe:** `dedupe_key = sha256(primary_scene_id | editorial_angle_key | format_class)` UNIQUE across rows not `REJECTED`/`RETIRED` (partial unique index). Replay of the same run: `(agent_run_id, output_ordinal)` UNIQUE.
- **FKs:** `primary_scene_id → anime_scene_intelligence` (nullable for scene-less formats such as anime-history pieces, in which case `anime_title_id` is required), `anime_title_id`, `research_candidate_id` (optional), `agent_run_id`. Supporting scenes in `editorial_opportunity_scenes` (join table).
- **Human-assigned?** No.

#### `script_id` (table `content_scripts`)
- **Owner:** CF-004 only.
- **Created when:** CF-004 drafts a script for an approved `content_candidate_id`.
- **Immutability:** ID-3. G2 approves this exact ID + `content_sha256`.
- **Consumers:** G2, CF-005, CF-006, CF-009.
- **Dedupe:** `(content_candidate_id, revision_number)` UNIQUE. At most one script per candidate may be `APPROVED` at a time (partial unique index).
- **FKs:** `content_candidate_id`, `revision_of_script_id`, `agent_run_id`.
- **Human-assigned?** No.

### 2.4 Source-governance identities

#### `source_package_id` (table `publication_source_packages`)
- **Owner:** CF-005 only.
- **Created when:** CF-005 assembles candidate publication material for an approved script.
- **Immutability:** ID-3; package items frozen once `REVIEW`. G3 approves this exact ID + `content_sha256`.
- **Consumers:** G3, CF-006, CF-007 (compliance check), G4 (compliance check).
- **Dedupe:** `(script_id, revision_number)` UNIQUE; one `APPROVED` package per script at a time.
- **FKs:** `script_id`, `revision_of_source_package_id`, `agent_run_id`.
- **Human-assigned?** No.

#### `source_item_id` (table `publication_source_items`) — added in Sprint 0
- **Owner:** CF-005.
- **Purpose:** one row per candidate piece of material (official trailer segment, original graphic, still…) inside a package.
- **Dedupe:** `(source_package_id, item_ordinal)` UNIQUE.
- **FKs:** `source_package_id`, `source_episode_id` (nullable), `scene_id` (nullable).

#### `gate_decision_id` (table `gate_decisions`) — added in Sprint 0; replaces `publication_source_decisions`
- **Owner:** the governance gate function `cf.record_gate_decision()` only, called from a human-authenticated surface. No agent role can insert.
- **Immutability:** append-only. Corrections are new rows with `supersedes_gate_decision_id`.
- **Consumers:** every downstream validator; the status-guard trigger.
- **Dedupe:** `idempotency_key` UNIQUE (the surface sends one per click/submission).
- **Human-assigned?** No (the human chooses the decision; the system assigns the ID).

### 2.5 Production identities

#### `production_manifest_id` (table `production_manifests`)
- **Owner:** CF-006 only.
- **Created when:** CF-006 plans an approved script + approved package.
- **Immutability:** ID-3; immutable once `READY`.
- **Consumers:** CF-007, G4.
- **Dedupe:** `input_hash = sha256(script_id | source_package_id | manifest_schema_version | planner_version)` UNIQUE — the same approved inputs and planner version always resolve to the same manifest (replay-safe). `(script_id, source_package_id, revision_number)` UNIQUE.
- **FKs:** `script_id`, `source_package_id`, `agent_run_id`.
- **Human-assigned?** No.

#### `production_job_id` (table `production_jobs`)
- **Owner:** CF-007 only.
- **Created when:** CF-007 expands a READY manifest into executable jobs (narration, captions, graphics, render).
- **Immutability:** job definition immutable; run state mutable (`QUEUED → RUNNING → SUCCEEDED/FAILED/CANCELLED`).
- **Consumers:** CF-007 itself, CF-000 later.
- **Dedupe:** `idempotency_key = sha256(production_manifest_id | job_type | segment_ref | attempt_group)` UNIQUE. A retry increments `attempt_count` on the same row; a deliberate re-do uses a new `attempt_group`.
- **FKs:** `production_manifest_id`, `agent_run_id`.
- **Human-assigned?** No.

#### `asset_id` (table `content_assets`)
- **Owner:** CF-007 (generated assets) or the asset-intake path (human-supplied original graphics, approved source files).
- **Immutability:** the bytes an asset_id names never change: `sha256` UNIQUE. New bytes = new asset_id.
- **Consumers:** CF-007, renders, G4.
- **Dedupe:** `sha256` UNIQUE. Re-registering the same bytes returns the existing asset_id.
- **FKs:** `production_job_id` (nullable), `source_item_id` (nullable — required when the asset is third-party material), `agent_run_id`.
- **Human-assigned?** No.

#### `render_id` (table `renders`) — table added in Sprint 0
- **Owner:** CF-007 only.
- **Created when:** a master video file is produced and registered.
- **Immutability:** ID-3; one render = one master file (`master_asset_id`). G4 approves this exact ID + checksum.
- **Consumers:** G4, CF-008, CF-009.
- **Dedupe:** `(production_manifest_id, render_revision)` UNIQUE; `master_asset_id` UNIQUE.
- **FKs:** `production_manifest_id`, `master_asset_id → content_assets`, `agent_run_id`.
- **Human-assigned?** No.

### 2.6 Distribution and learning identities

#### `published_content_id` (table `published_content`)
- **Owner:** CF-008 only.
- **Meaning:** the one V&A content object created from a G4-approved render. Platform posts are distributions of it.
- **Dedupe:** `render_id` UNIQUE (one content object per approved render).
- **FKs:** `render_id`, `content_candidate_id`, `script_id` (denormalised lineage for analytics, CHECK-consistent through the chain).
- **Human-assigned?** No.

#### `platform_post_id` (table `platform_posts`) — added in Sprint 0
- **Owner:** CF-008 only.
- **Meaning:** one distribution of a published_content object to one platform (YouTube Shorts, TikTok, Instagram Reels).
- **Dedupe:** `(published_content_id, platform)` UNIQUE among non-RETIRED rows; `(platform, external_post_id)` UNIQUE where not null. `publish_idempotency_key` UNIQUE so an upload is attempted at most once per key.
- **FKs:** `published_content_id`, `upload_asset_id → content_assets`, `agent_run_id`.

#### `performance_snapshot_id` (table `performance_snapshots`)
- **Owner:** CF-009 only.
- **Immutability:** append-only; never updated.
- **Dedupe:** `(platform_post_id, metric_window, captured_bucket)` UNIQUE, where `captured_bucket` = capture time truncated to the hour.
- **FKs:** `platform_post_id`, `agent_run_id`.

#### `learning_log_id` (table `content_learning_log`)
- **Naming note:** the blueprint calls this `learning_record_id`; the Sprint 0 brief and table name use `learning_log_id`. **Proposed canonical name: `learning_log_id`.**
- **Owner:** CF-009 only.
- **Immutability:** append-only; a revised conclusion is a new row with `supersedes_learning_log_id`.
- **Dedupe:** `(agent_run_id, output_ordinal)` UNIQUE.
- **FKs:** `published_content_id` (nullable for cross-content learnings), `agent_run_id`; evidence snapshot IDs in `evidence_snapshot_ids uuid[]`.

### 2.7 Operational identities

#### `agent_run_id` (table `agent_runs`) — added in Sprint 0
- **Owner:** the first deterministic node of every CF workflow (before any model call).
- **Meaning:** one invocation of one CF agent version.
- **Dedupe:** `idempotency_key = sha256(agent_code | agent_version | canonical_json(sorted input IDs) | input_state_hash)` UNIQUE. A replay with the same key finds the existing run and returns its outputs without new writes or provider calls.
- **Records:** n8n workflow ID, workflow version ID, execution ID, prompt version, model requested, provider call count, paid call count, estimated cost, run state.

#### `reviewer_id` (table `reviewers`) — added in Sprint 0 (from A1-FOUNDATION)
- **Owner:** humans, via a governed setup step (Sprint 3 at the earliest).
- **Meaning:** a named human allowed to decide specific gates. Agents and service accounts are never reviewers.

## 3. Lineage that must always resolve (blueprint §23)

```text
platform_post_id → published_content_id → render_id → production_manifest_id
  → source_package_id → script_id → content_candidate_id → scene_id
  → source_episode_id → anime_title_id → franchise_id
```

and forward:

```text
platform_post_id → performance_snapshot_id → learning_log_id → (input to) research_candidate_id / content_candidate_id
```

Every arrow is a NOT NULL foreign key except `content_candidate_id → scene_id` (nullable for scene-less formats, documented above) and the learning feedback arrow (soft, by reference only — see the dependency map).
